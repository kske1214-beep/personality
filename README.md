# 面接準備OS

求人票を面接評価軸に変換し、面接回答・逆質問・競合比較まで一気通貫で準備するWebアプリです。

## 主な機能
- MUST条件 / WANT条件 / 隠れ評価軸の抽出
- 面接評価軸スコア（再現性・論理性・数字責任・自走力・改善力・巻き込み力・カルチャーフィット）
- 人事向け / 現場責任者向け / 代表向けの逆質問
- 志望動機・自己PR・転職理由・想定質問・深掘り質問の自動生成
- 面接通過率予測（勝率スコア）
- 競合比較（年収・裁量・成長環境・評価制度・AI活用度・内製化思想）

## 使い方
`index.html` をブラウザで開いて利用してください。
